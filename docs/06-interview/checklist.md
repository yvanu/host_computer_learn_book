# 06 · 求职知识清单和复盘

你已经会后端开发，转上位机岗位时，简历上最好突出**端到端设备数据链路**，而不是只展示一个漂亮页面。

## 面试中应该讲清的十个问题

1. 上位机和 PLC 的分工是什么？哪些实时、安全动作必须留在控制器侧？
2. 为什么 TCP 会出现半包、粘包？如何用长度字段或分隔符处理？
3. Modbus RTU 与 Modbus TCP 的帧结构有什么区别？
4. 03、04、06、10 功能码分别对应什么行为？
5. 为什么寄存器 40001 不一定按数字 40001 发送？
6. WPF 的 DataContext、Binding 和 INotifyPropertyChanged 分别负责什么？
7. 为什么在 UI 线程使用 `.Result` 可能造成死锁？
8. 怎样实现连接超时、断线感知和受控重连？
9. 采集频率高但 UI 更新慢时如何设计队列与背压？
10. 为什么不能对所有设备控制命令一律自动重试？

## 简历项目建议（做到后再写）

> **工业设备监控上位机（C# / WPF / TCP / Modbus）**：采用 MVVM 管理实时测点与连接状态，抽象通信与解析逻辑，支持设备断线提示、参数校验、采样记录、异常日志，并通过模拟设备完成边界场景测试。

仅把**实际完成且可演示**的功能写入简历。上面是目标状态，不是 v0.1 目前已全部实现的功能。

## 深挖时的讲述顺序

场景 → 为什么选择协议 → 数据从哪里来 → 如何保证 UI 不冻结 → 错误如何定位 → 如何验收。

## 后续拓展

基础稳固后再根据岗位选择 OPC UA、CAN、PLC 编程、SCADA、工业组态、C++ Qt、LabVIEW、运动控制等方向。不要在理解 TCP 与寄存器之前一口气打开所有分支。

**验收：** 不看资料能向他人解释自己写的每一条数据从设备到 UI 的路径，并能定位常见异常。
