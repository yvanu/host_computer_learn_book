# 12 周学习路线

> 适用对象：有 Python、Flask、SQL、TCP、Celery/异步任务、Linux 服务部署等经验，但第一次开发 Windows 上位机的人。推荐每天 1～2 小时，每周至少做一次小实验记录。

## 阶段目标

| 时间 | 能力目标 | 需要交付的成果 |
| --- | --- | --- |
| 第 1 周 | 认识上位机、安装 .NET、掌握 C# 常用语法 | C# 控制台程序，正确解析模拟测量数据 |
| 第 2 周 | 熟悉异常、泛型、集合、Task、async/await | 可取消的异步数据采集小程序 |
| 第 3 周 | 掌握 WPF 布局、XAML、Binding | 能显示设备参数的桌面面板 |
| 第 4 周 | 理解 MVVM、命令和 UI 线程 | 界面不阻塞、连接状态可见 |
| 第 5 周 | 理解二进制、大小端、校验、帧结构 | 从字节中解析有符号数与浮点数 |
| 第 6 周 | 掌握 TCP 长连接、拆包与重连设计 | 连接模拟设备，实时读数与指令回执 |
| 第 7 周 | 熟悉串口、RS-232/485、串口调试 | 能配置串口参数，用模拟端口进行收发 |
| 第 8 周 | 理解 Modbus RTU/TCP、寄存器与功能码 | 读取模拟设备的寄存器数据 |

以上是学习时间预估，不代表已经完成全部章节。现在你可以直接完成 [Modbus TCP 本地实验](/04-modbus/tcp-lab)、[CRC16 实验](/04-modbus/crc-lab)，并对照 [联调排障清单](/04-modbus/debugging) 练习异常情况。之后可进入 [WPF 工业监控台](/05-project/wpf-lab) 将采集、报警与 SQLite 组合在一起。实际编写/测试状态以 [内容进度](/PROGRESS) 为准。

## 不需要从零学的东西

- HTTP / REST / JSON：仍然有用，但设备通信常用**原始字节流**而非 HTTP。
- TCP/IP：你已有网络经验，要继续补充**长连接断线、半包、分帧、心跳**。
- 数据库：SQL 和数据建模能迁移到 SQLite / PostgreSQL，重点是**采集与存储的线程隔离**。
- 异步任务：理解 Celery/asyncio，有助于理解 C# 的 Task；但 **WPF 多了一个必须保护的 UI 线程**。

## 学习优先级

**主线：C# + .NET 10 + WPF + TCP/Modbus。** 不在入门期同时展开 C++/Qt、LabVIEW、CANopen、EtherCAT、OPC UA，它们作为后续按岗位需求选择的分支。

**先模拟再真机：** 在本地可以完整练习通信与 UI。接真实设备需要另外学习安全联锁、指令互锁、厂商寄存器映射和现场调试流程。

## 推荐学习节奏

一个晚上的节奏：20 分钟读概念、35 分钟运行/修改代码、20 分钟做练习、10 分钟记录问题。连续两课卡住时优先复现现象、保存报文、缩小问题范围，不盲目换框架。

## 每个阶段的合格条件

- **基础合格：** 能不用资料解释 C# 属性、事件、Task 与 Python 概念的差异。
- **通信合格：** 能说清 TCP 没有消息边界，能处理拆包/半包及异常断开。
- **桌面合格：** 拔掉设备连接不会造成 UI 假死。
- **项目合格：** 从启动、连接、数据展示、断线提示到退出，流程没有不可恢复状态。
