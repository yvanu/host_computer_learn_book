# 00-1 · 这门课怎么学

## 本课目标

你能描述“上位机”做什么、哪些能力能从后端迁移、第一阶段交付什么。

## 上位机究竟是什么？

上位机通常指运行在 PC/工业计算机上的控制与监控应用。它连接 PLC、单片机、仪器或网关，**读取状态、显示实时数据、记录历史、下发经过校验的控制指令**。

```text
设备（传感器 / PLC） ── 串口、TCP、Modbus ──> C# 通信层
                                            │
                                       解析 / 校验
                                            │
                       WPF View ← ViewModel / 状态
                                            │
                                    SQLite / CSV / 日志
```

你熟悉的 Web 后端通常由请求触发处理；上位机更多维护一段**长生命周期的设备会话**：启动 → 连接 → 采集 → 断线 → 重连 → 关闭。设备不一定会返回 JSON，可能返回带校验码的十六进制字节。

## 为什么主线选 C# + WPF？

- C#：类型系统严格，具备事件、属性、Task、NetworkStream 等常用能力。
- WPF：适合 Windows 桌面开发，原生绑定、模板、命令、数据可视化能力成熟。
- .NET 10：长期支持版本，符合新项目学习与演示需求。
- Qt/C++ 和 PySide6 并非错误选择，但同时学习三套框架会把注意力从设备通信主线上移走。

## 学习三条原则

1. **先跑通可观察的最小实验。** 每个练习必须有输入、输出或日志。
2. **先处理正常路径，再补失败路径。** 任何设备都会掉线、超时或回复异常。
3. **严格区分演示与真实设备。** 模拟器可以随便重启，真实电机、阀门和加热设备不能盲目下发控制命令。
