# 05-2 · 综合项目的验收计划

## M1：能连、能看（本期）

- [ ] 在 Windows 上启动模拟设备
- [ ] 打开 WPF 监控窗口
- [ ] 点击连接后状态从“未连接”变化为“已连接”
- [ ] 温度/压力/转速持续刷新
- [ ] 断开模拟器后 UI 不冻结
- [ ] 能关闭窗口并释放连接

记录：Windows 版本、.NET SDK 版本、运行截图、日志片段。

你也可以直接使用 v0.3 [WPF + Modbus TCP 监控台](/05-project/wpf-lab) 完成更完整的模拟实战；本页仍作为分阶段的独立验收清单。

## M2：能解释报文（后续）

- [ ] 数据帧分隔/长度合法性校验
- [ ] CRC16 与 Modbus RTU 测试向量
- [ ] Modbus TCP 读取寄存器
- [ ] 协议异常码、超时与重试策略

记录：抓包内容、功能码、寄存器偏移、解码结果与预期值。

## M3：真正可用的监控台（v0.3 已覆盖部分功能）

- [ ] 多设备配置和连接
- [ ] 采集轮询和限速刷新
- [ ] 本地 SQLite 历史存储（v0.3 已提供源码，待 Windows 运行验收）
- [ ] 告警阈值、告警确认和操作日志（v0.3 有固定阈值与近期事件；确认与持久化事件待补齐）
- [ ] CSV 导出、安装部署和退出清理

## M4：工程能力与求职演示（后续）

- [ ] 单元测试覆盖不合法/截断报文
- [ ] UI 长时间运行与断连压力测试
- [ ] 异常场景复现文档
- [ ] 架构说明、技术选型、截图及可复现启动步骤

通过标准不只是“程序能跑”，而是**没有网络连接/设备异常时也能可预测地失败**。如果当前机器缺少 Windows + .NET SDK，应在报告中标记未验证，不得谎称 WPF 已通过实机验收。
